# RIDO

Déposez ici :
- le manuel du format d'entrée RIDO (PDF) ;
- 3 à 5 fichiers d'entrée RIDO avec leurs sorties (déplacements, moments, efforts d'appui par phase).

Le convertisseur (`backend/sout/script/rido.py`) ne reprend **aucun mot-clé deviné** :
sa table de correspondance est vide tant que le manuel n'a pas été fourni et lu.
Vérifiez aussi que la licence RIDO autorise la lecture de son format par un autre outil.
